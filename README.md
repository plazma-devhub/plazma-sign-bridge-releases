# Plazma Sign Bridge — готовые сборки

Публичный канал подписанных сборок расширения для Chromium-браузеров на Windows.
Исходников серверной части в этом репозитории нет. Для скачивания не нужен вход в GitHub.

## Версия 0.2.5

Исправлен цвет текста кнопки оплаты в Bnovo, убрана вспомогательная подпись.
В настройках → «Оплата» можно изменить заголовок блока и название кнопки.
По умолчанию: «Оплата по ссылке Бани и Услуги | Касса Дяченко В.Н» и «Сформировать ссылку».
Эти подписи отображаются в карточке бронирования и панели шахматки; касса задаётся на сервере Plazma Pay.

«Сформировать ссылку» в карточке бронирования и боковой панели шахматки Bnovo.
Предварительный просмотр показывает услуги, время, стоимость, оплаченную часть и остаток.
Можно указать сумму или выбрать 30%, 50% либо весь остаток, изменить назначение и срок ссылки.
Используется текущая касса Plazma Pay. Перед созданием проверяются Bnovo, сервис, касса и платёжная система.
Ссылка создаётся только по отдельному подтверждению и копируется отдельной кнопкой.
Повторное открытие возвращает сохранённую ссылку; при потере ответа повторяются те же условия.
Оплата автоматически не вносится в Bnovo. Для одного бронирования используется одна привязка предоплаты;
не меняйте её условия одновременно с разных компьютеров.

Сохраняются индикатор Plazma Pay в окне расширения и настройках, русские подписи, группы настроек,
светлая и тёмная темы. Прежние настройки сохраняются при обновлении.

### Как проверить

1. Обновитесь до 0.2.5 через кнопку расширения и перезагрузите Bnovo.
2. Откройте карточку неоплаченной брони бани или её панель в шахматке → «Сформировать ссылку».
3. Проверьте номер, услугу, время, остаток и кассу. Выберите 50%, затем закройте окно: счёт не создаётся.
4. Для согласованной проверки создания снова откройте окно, укажите нужную сумму, нажмите «Создать ссылку» → «Копировать ссылку».
5. Проверьте сумму и назначение в Plazma Pay. Повторное открытие должно вернуть ту же ссылку.
Оплачивать её для проверки создания не требуется; отражение предоплаты в Bnovo выполняется отдельно.

## Обновление установленного расширения

1. Сохраните изменения на рабочих страницах и завершите подписание.
2. Откройте расширение и нажмите **«Проверить обновления» → «Обновить»**.
3. После перезапуска проверьте версию **0.2.5** и откройте **«Настройки»**.
4. Обновите вкладки Bnovo, EMIS и Контур. Для возврата доступна кнопка **«Откатить»**.

Если помощник версии 2 уже подключён, переустанавливать его не требуется.
Автоматическое обновление требует отдельной рабочей папки вне Git checkout.

## Установка с нуля

1. Скачайте [полный комплект Windows 0.2.5](https://github.com/plazma-devhub/plazma-sign-bridge-releases/releases/download/extension-v0.2.5/plazma-sign-bridge-windows.zip) и полностью распакуйте в постоянную папку.
2. Откройте `chrome://extensions` (Edge: `edge://extensions`), включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите подпапку `bnovo-sign-bridge`.
4. Откройте расширение и скопируйте его ID. Запустите `Install-Updater.cmd`, выберите установленную папку расширения и вставьте ID. Запрос предыдущего ID пропустите клавишей Enter.
5. Перезагрузите расширение, проверьте сообщение «Помощник подключён», заполните настройки подключения и сохраните их.

Если нужно обновить только первоначального помощника версии 1, скачайте [отдельный ZIP помощника версии 2](https://github.com/plazma-devhub/plazma-sign-bridge-releases/releases/download/extension-v0.2.5/plazma-sign-bridge-updater-windows.zip) и запустите установщик с прежней папкой и ID. Само расширение затем обновляется по кнопке.

## Настройки

Разделы: подписание документов, оплата Plazma Pay, подключение Bnovo, данные гостей EMIS, рабочие настройки и дополнительные технические параметры.
Одна кнопка **«Сохранить настройки»** или **Ctrl+S** сохраняет все разделы.
Адреса рабочих серверов и данные доступа необходимо получить у администратора; в сборки они не включены.
