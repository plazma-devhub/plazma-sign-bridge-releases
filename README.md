# Plazma Sign Bridge — готовые сборки

Публичный канал подписанных сборок расширения для Chromium-браузеров на Windows.
Исходников серверной части в этом репозитории нет. Для скачивания не нужен вход в GitHub.

## Версия 0.2.7

Связь конкретного счёта Bnovo со ссылкой Plazma Pay и подготовка ручного зачисления.
Одна серверная привязка на каждый счёт; разные счета одной брони имеют разные ссылки.
После подтверждённой реальной оплаты кнопка «Зачесть в Bnovo» заполняет родную форму.
Сохранение выполняет администратор: первое нажатие «Сохранить» проверяет сведения,
после сообщения «Проверено» нужно повторное ручное подтверждение.
Ни создание платежа, ни нажатие сохранения расширение автоматически не выполняет.
Результат сверяется по реальному платежу Bnovo, сумме, счёту и уникальной метке Pay.
Повторное внесение и неоднозначные результаты блокируются.

Для текущего канала нужен обновлённый сервер Plazma Pay с поддержкой привязок v1
и настроенным соответствием кассы юридическому лицу Bnovo. Данные доступа и ID
получателя не включаются в публичную сборку. Прежние настройки сохраняются.

### Как пользоваться

1. Обновитесь до 0.2.7 через кнопку расширения и перезагрузите Bnovo.
2. Создайте обычный документ Bnovo типа «Счёт» на сумму предоплаты и правильного получателя.
   Для 50% нужна отдельная сумма счёта; онлайн-счёт с другой платёжной ссылкой не переиспользуется.
3. У строки счёта откройте Pay либо выберите счёт в панели шахматки. Проверьте сведения.
4. «Создать ссылку» → «Копировать ссылку». Открытие окна и копирование ничего в Bnovo не создают.
5. После фактической оплаты гостем нажмите «Зачесть в Bnovo», проверьте заполненную родную форму
   и сохраните её вручную по подсказке. Касса Pay оформляет чек; повторный чек Bnovo не включается.
6. После перезагрузки при необходимости нажмите «Проверить зачисление». Оплаченная сумма и родной
   статус Bnovo доступны коллегам без расширения.

Если форма закрыта без сохранения, выполните сверку и явно подтвердите «Форма не была сохранена».
При потере ответа не повторяйте внесение вслепую. Старые ссылки на бронирование автоматически
не переносятся на счета: перед новой ссылкой проверьте оплату старой и отмените неиспользованную.

Платёжный блок в шапке бронирования не добавляется. Заголовок и кнопка панели шахматки
меняются в настройках → «Оплата». Без настроек Pay данные Bnovo всё равно отображаются.

## Обновление установленного расширения

1. Сохраните изменения на рабочих страницах и завершите подписание.
2. Откройте расширение и нажмите **«Проверить обновления» → «Обновить»**.
3. После перезапуска проверьте версию **0.2.7** и откройте **«Настройки»**.
4. Обновите вкладки Bnovo, EMIS и Контур. Для возврата доступна кнопка **«Откатить»**.

Если помощник версии 2 уже подключён, переустанавливать его не требуется.
Автоматическое обновление требует отдельной рабочей папки вне Git checkout.

## Установка с нуля

1. Скачайте [полный комплект Windows 0.2.7](https://github.com/plazma-devhub/plazma-sign-bridge-releases/releases/download/extension-v0.2.7/plazma-sign-bridge-windows.zip) и полностью распакуйте в постоянную папку.
2. Откройте `chrome://extensions` (Edge: `edge://extensions`), включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите подпапку `bnovo-sign-bridge`.
4. Откройте расширение и скопируйте его ID. Запустите `Install-Updater.cmd`, выберите установленную папку расширения и вставьте ID. Запрос предыдущего ID пропустите клавишей Enter.
5. Перезагрузите расширение, проверьте сообщение «Помощник подключён», заполните настройки подключения и сохраните их.

Если нужно обновить только первоначального помощника версии 1, скачайте [отдельный ZIP помощника версии 2](https://github.com/plazma-devhub/plazma-sign-bridge-releases/releases/download/extension-v0.2.7/plazma-sign-bridge-updater-windows.zip) и запустите установщик с прежней папкой и ID. Само расширение затем обновляется по кнопке.

## Настройки

Разделы: подписание документов, оплата Plazma Pay, подключение Bnovo, данные гостей EMIS, рабочие настройки и дополнительные технические параметры.
Одна кнопка **«Сохранить настройки»** или **Ctrl+S** сохраняет все разделы.
Адреса рабочих серверов и данные доступа необходимо получить у администратора; в сборки они не включены.
